# Nieves Site

Face-scan site attendance for Nieves Construction Services.
Served at https://app.nievesconstructionservices.com (GitHub Pages).

- `index.html`, `app.js`, `app.css`: the app
- `face/`: face-recognition library and models (run on the phone)
- `sw.js`, `manifest.webmanifest`, icons: installable app

Data lives in Supabase behind row-level security; this repository holds no secrets.
